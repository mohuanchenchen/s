# s

GitHub Pages 短链站点，基于 [gh-pages-url-shortener](https://github.com/nelsontky/gh-pages-url-shortener)。

- 首页 <https://mohuanchenchen.github.io/s> 跳转到《提问的智慧》中文版。
- 在 [mohuanchenchen/gh-pages-url-shortener 的 Issues](https://github.com/mohuanchenchen/gh-pages-url-shortener/issues) 中，以完整 `https://` 目标 URL 为标题创建 Issue。Issue `#N` 对应 `https://mohuanchenchen.github.io/s/N`。
- `#1` 同时写入了 `404.html` 的 `STATIC_LINKS`，不依赖 GitHub 公共 API。其他编号仍由公共 API 解析，可能受访客 IP 的限流影响。
